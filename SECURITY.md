## Reporting a Vulnerability

We take the security of Swarm Animation Skill seriously.

If you believe you have discovered a vulnerability, please **do not report it through public GitHub issues**.

Instead, please report security vulnerabilities through [GitHub Private Vulnerability Reporting](https://github.com/badhonvitality/swarm-animation-skill/security/advisories/new) under the repository's Security tab.

### What to Include
- Detailed description of the vulnerability.
- Steps to reproduce or proof-of-concept code.
- Potential impact and affected components.

### Our Commitment
- We will acknowledge receipt of your report within 48 hours.
- We will provide a timeline for assessing and remediating the issue.
- Once fixed, we will publish a release note and credit you (if desired).
