## [1.0.0] - 2026-11-07

### Added
- **Initial Public Release** of Swarm Animation Skill (`badhonvitality/swarm-animation-skill`).
- **Skills CLI Distribution**: Native support for installation via `npx skills add badhonvitality/swarm-animation-skill`.
- **Hybrid Canvas Architecture**: Decoupled rendering with Offscreen Canvas text layout caching, SVG vector drafting surfaces, and DOM element versioning.
- **Boids Flocking Physics**: Newtonian orbital mechanics with harmonic breathing radius, alternating tangential swirl, and 90px neighbor velocity alignment.
- **Elastic Collision Repulsion**: 48px boundary around user cursor with velocity momentum reflection and impulse repulsion.
- **Multi-Agent Cursors**: 9 collaborative Figma-style SVG cursor shapes with dynamic heading rotation and click-depression scaling.
- **Autonomous Task Coroutines**: ES6 generator coroutines executing path drawing, card drafting, text typing with realistic keystroke cadences, and Option-drag duplication with red delta measurement overlays.
- **Reference Documentation**: Comprehensive modular guides for animation systems, mouse control, physics engines, React architecture, design systems, and implementation.
- **Standalone Examples**: Reusable reference code for canvas components, agent cursors, mouse tracking hooks, and physics simulations.
- **CI Workflow**: Automated GitHub Actions workflow validating skill structure, YAML frontmatter, and production React builds.
